## 版本速查

- **v0.2.8（当前）**：发布包不再混入本地运行时文件（曾含 dashboard 密码
  哈希与运行库）；打包脚本改为由 git 清单驱动并自带泄漏自检。
- **v0.2.7**：用户在 WebUI 把数字字段填成非数字时，插件不再
  「加载成功但每轮静默失效」；「最近 N 天」统计改为自然日区间；
  知识库与联网工具在上游返回意外形状时优雅降级。
- **v0.2.6**：商店卡片的作者从平台账号 `cosc` 修正为插件作者
  `TechSauce`（科技酱）；新增 21 项 Logo 解析链路与商店元数据契约测试。
- **v0.2.3**：`/superai memory` 子指令不可达、工具归属断裂、
  耗时统计污染、单模型用户记忆静默失效 —— 四个问题全部修复；
  新增「开发文档 / 使用文档 / 契约文档」体系。
- **v0.2.2**：根 `main.py` 入口 + 钩子 `self` 绑定修复；
  新增加载器契约测试与真实 AstrBot 端到端联调。
- **v0.2.1**：SuperRouter / SuperMemory / SuperAgent / 工作流 /
  用量统计 / Studio 面板首次实现。
