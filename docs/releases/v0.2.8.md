# v0.2.8 —— 发布包泄漏修复

发布日期：2026-09-27

## 一句话

v0.2.7 发布后，我在核验 GitHub Release 附件时**把包下载回来解压检查**，
发现发布包里混进了本机的运行时文件 —— 其中包含 `data/cmd_config.json`
（内含 dashboard 密码哈希）与 `data/data_v4.db`（完整运行库）。

这一版修的是**发布流程本身**，插件运行逻辑与 v0.2.7 一致。

## 问题

`scripts/build_plugin_zip.sh` 此前直接 `tar` **工作区**：

```bash
tar --create --exclude='./.git' --exclude='./tests' ... . | tar --extract ...
```

`data/` 虽然被 `.gitignore` 忽略，但它**不是 git 能替你挡住的** ——
打包脚本看的是磁盘，不是 git 索引。只要维护者在打包前本地跑过一次插件
（或跑过 `scripts/e2e_smoke.py`），工作区里就会留下：

```
data/cmd_config.json      # dashboard 密码哈希、admins_id、各 provider 配置
data/data_v4.db           # AstrBot 完整 SQLite 运行库（几百 KB）
data/data_v4.db-shm/-wal
data/t2i_templates/       # 文本转图模板
```

这些会被原样打进发往 AstrBot 官方市场的 ZIP。实测（用旧脚本）：

```
$ bash scripts/build_plugin_zip.sh
$ unzip -l dist/astrbot_plugin_superai-v0.2.7.zip | grep data/
astrbot_plugin_superai/data/cmd_config.json
astrbot_plugin_superai/data/data_v4.db
astrbot_plugin_superai/data/data_v4.db-shm
astrbot_plugin_superai/data/data_v4.db-wal
astrbot_plugin_superai/data/t2i_templates/astrbot_powershell.html
...
```

两个后果：

1. **泄露打包者本机配置**（密码哈希、管理员 ID、provider 配置）；
2. 给每个用户凭空塞进几百 KB 与插件运行无关的文件。

## 修复

打包来源改为 **`git ls-files` 的已提交文件**，按白名单前缀收集：

```bash
while IFS= read -r file; do
    ...
done < <(git ls-files)
```

**为什么不只是多加几个 `--exclude`**：那依赖「记得加」。下次新增一个运行时
目录（比如 `cache/`）就会重演同一个问题。改为问 git 要清单后，
`.gitignore` 天然成为唯一真相来源 —— 任何被忽略的本地产物都不可能被打包。

脚本内同时加了两道**显性自检**（宁可打包失败，也不静默产出坏包）：

- 收集到的文件数少于 10 → 失败（说明清单过滤规则写坏了）；
- 产物中检出 `data/`、`.db`、`cmd_config.json`、`.git/` 等禁止内容 → 失败。

## 新增 4 项发布包内容契约测试

`tests/test_repo_health.py`：

| 测试 | 守住什么 |
| --- | --- |
| `test_package_has_no_runtime_artifacts` | 包内不得出现数据库 / 配置 / 缓存 / 测试 / 文档 |
| `test_package_contains_runtime_essentials` | 入口、元数据、图标、schema、各子包、面板、i18n 必须齐全 |
| `test_package_version_matches_repo` | 包内 `metadata.yaml` 与 `version.py` 的版本必须与仓库一致（防止打出旧包） |
| `test_build_script_is_git_driven` | 打包脚本必须由 git 清单驱动（**根因防线**，防止有人改回去） |

## 验证

- 旧脚本实测打进 7 个运行时条目；新脚本产出 **38 项、零泄漏**。
- 把新包**解压安装进真实 AstrBot 4.28.1**：正常加载、3 个工具与 7 个
  Web API 全部就位、版本显示 `v0.2.8`。
- `pytest tests`（真实 AstrBot 4.28.1）→ **277 passed**
- `ASTRBOT_REF=/nonexistent pytest tests` → **245 passed, 22 skipped**
- `ruff check .` + `ruff format --check .` → 全通过

## 受影响范围

- **v0.2.7 的 CNB 与 GitHub Release 附件已替换为重新构建的干净包**。
  该版本的插件功能本身没有问题，只是发布附件需要更新。
- 若你已下载过旧附件，建议重新下载；如曾把该包解压到 `data/plugins/`，
  请删除包内多出来的 `data/` 子目录（插件本身不使用它）。

## 无破坏性变更

配置项、数据格式、指令签名与 v0.2.7 完全一致。
